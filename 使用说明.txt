========================================
        弹幕背单词 - 使用说明
========================================

  CC-Made

【这是什么】
单词标签从屏幕顶部从右往左飘过，平时只显示英文，
鼠标放上去就停住并显示中文意思，不影响你正常用电脑。

----------------------------------------
【怎么启动】
----------------------------------------

1. 双击「启动弹幕背单词.bat」
   → 单词开始在屏幕顶部飘，没窗口、不挡操作

2. 双击「启动词库管理.bat」
   → 打开词库表格，可以增删改单词、补例句

----------------------------------------
【操作方式】
----------------------------------------

鼠标移到单词上：
  - 所有单词停住，其他变半透明
  - 当前单词向下展开，显示词性+中文意思

鼠标左键点击单词：
  - 播放英文发音（离线，Windows自带语音）
  - 如果有例句，下方弹出例句气泡

鼠标中键点击单词：
  - 标记为"已掌握"，变灰，以后不再出现

鼠标右键点击单词：
  - 菜单：播放发音 / 标记已掌握

屏幕右下角托盘（紫色W图标）：
  - 右键：暂停弹幕 / 点击模式 / 重置已掌握 / 退出

点击模式（两种，托盘里单选）：
  - 智能模式：游戏/全屏时单词自动点不到（点击穿透），其他情况可点
  - 始终可点：任何时候单词都能点

----------------------------------------
【词库管理】
----------------------------------------

打开词库管理窗口后：
- 双击任意格子直接编辑，自动保存
- 「添加单词」：加新词
- 「删除选中」：删掉不要的词
- 「重置已掌握」：把所有词重新标记为未掌握
- 例句两列可以自己填，弹幕里点单词会显示

当前词库：743个考研核心词汇（按真题词频排序）

----------------------------------------
【文件说明】
----------------------------------------

danmu_words.py      弹幕插件主程序（不用动）
word_manager.py    词库管理工具（不用动）
words.json          词库数据（可以用记事本直接打开编辑）
gen_words.py        词库生成脚本（备用，不用动）
启动弹幕背单词.bat   双击启动弹幕
启动词库管理.bat     双击打开词库管理

----------------------------------------
【注意】
----------------------------------------
- 需要电脑装了 Python 3.9+ 和 PySide6（命令行运行 pip install PySide6）
- 发音用的是 Windows 自带英文语音，离线可用
- 退出弹幕：右下角托盘紫色W图标 → 右键 → 退出
