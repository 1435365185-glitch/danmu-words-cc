# 弹幕背单词（Danmu Words）

桌面悬浮弹幕背单词小工具：单词像弹幕一样在屏幕顶部飘过，考研核心词汇，鼠标悬停显示中文释义、点击发音并显示例句。

## 功能

- 单词在屏幕最顶部一行横向飘动（可调速度、密度、透明度）
- 鼠标悬停单词：所有单词停住，其他单词变半透明，当前单词向下展开显示中文
- 鼠标左键点击单词：英文发音（Windows 自带语音，离线可用）+ 显示例句
- 中键：标记已掌握；右键托盘菜单管理
- 两种点击模式：智能模式（游戏/全屏时自动点不到）/ 始终可点
- 词库管理工具：增删改单词（考研核心词约 700+）

## 文件说明

- `danmu_words.py` — 主程序（弹幕）
- `word_manager.py` — 词库管理工具
- `words.json` — 词库数据
- `gen_words.py` — 词库生成脚本
- `启动弹幕背单词.bat` — 双击启动弹幕
- `启动词库管理.bat` — 双击打开词库管理

## 运行要求

- Windows 10/11
- Python 3.9+（需安装 PySide6：`pip install PySide6`）

## 使用方法

1. 双击 `启动弹幕背单词.bat` 启动（出现黑色窗口表示程序在运行，关闭窗口即退出）
2. 右下角托盘紫色 W 图标：暂停/模式切换/重置已掌握/退出
3. 双击 `启动词库管理.bat` 管理单词

## 注意

- 程序需要 Python 环境：先安装 Python（勾选 Add to PATH），再运行 `pip install PySide6`
- 如果双击 bat 闪退，先在命令行运行 `py danmu_words.py` 查看报错
